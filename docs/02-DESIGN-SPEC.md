# 02 · 视觉与交互规范

设计血统：**dsh-claude-style 0.20.3** 的设计令牌（Claude Code Desktop 复刻主题）。原则：无纯黑、无冷灰；暖纸底；陶土橙是唯一强调色且可见面积 < 10%；衬线只用于展示级标题；输入框是整套「手感」的来源；动效短、轻、有回弹。

> 实施契约：UI 工程规范见 08-UI-ENGINEERING-SPEC.md 与 ../design/ui/tokens.css；组件尺寸、状态、令牌以 08 为准，本文保留设计意图与叙事。

## 3. 圆角 / 边框 / 阴影 / 间距

- 圆角：小控件 4/4.5/6，行与输入 7/8/9/10，卡片/浮层 12，输入面板 14，挂件 16，胶囊 999；精确 token 见 08 §1.3 与 ../design/ui/tokens.css。
- 边框：一律 1px；颜色 `--hairline`；不要用 2px 深色描边（焦点除外，见下）。
- 阴影三级：
  - 静置卡片：`0 2px 6px rgba(60,50,30,.045)`
  - 浮层/下拉：`0 18px 40px rgba(60,50,30,.14)`
  - 挂件/胶囊（桌面上）：只做 `inset 0 0 0 1px` 内描边（8%，未置顶 6%，hover 12%）；**不使用外投影/外发光**：Electron 透明窗口边界＝卡片边界，外投影会被矩形窗口裁切、只在圆角缺口露出灰边。2026-11-22 用户确认不需要「浮在桌面上、四周带大外投影」的效果后，原型与实现统一为内描边。
  - 独立透明窗口（挂件/胶囊/编辑/提示）内的弹层（modal、pop/dp-pop、toast）：用紧凑阴影 `--shadow-modal-window` / `--shadow-pop-window` / `--shadow-toast-window`（窗口只比内容大 24px/边，可完整渲染）；**不用大投影**：90px 级外投影会被窗口边界裁切、露出断边灰晕。应用窗口内（完整窗口）的弹层保留 `--shadow-modal` / `--shadow-pop` / `--shadow-toast` 大阴影（2026-11-22 规范调整，按渲染场景区分）。
- 间距：4px 节奏；挂件头部左右 14、内容区左右 6；列表行主窗口左右 10、挂件左右 8；区块间距 20–24；精确值见 08 §2.2/§2.3。

## 4. 三窗口规格

### 4.1 桌面挂件（主入口）
- 尺寸：**宽 352px**；高自适应，最大 520px（超出内容区滚动）；头部左右 14、内容区左右 6。
- 结构：拖拽区（顶部 14px 手柄 + 头部 22px，合计 36px 可拖）→ 标题「今天」+ 日期行 + 进度环 34px + 图钉/收起 → 待办分组 → 已完成折叠组 → 底部折叠输入按钮（「+ 添加任务」，点击展开 composer，最大 110）→ footer「双击空白处快速新增」。
- 任务行：内容驱动高度（padding 6px 8px），勾选框 18px（1.5px 边框圆形），标题 12.5px，元信息一行（时间 · 分隔点 · 文件夹/网页链接）。
- 无边框圆角 16；置顶时 `alwaysOnTop`；非焦点状态整体不透明度可设置 90%/80%。
- 收起胶囊：**284×54**、圆角 999，内容：32px 陶土圆形勾、`今天 4 项 · 1 项逾期`、最近任务副标题、右侧 26px 进度环；与挂件共用位置、切换时保持就近角坐标不变。hover 只加深内描边、**不做位移**（窗口高度＝胶囊高度，位移会让圆弧被窗口边界裁切）。

### 4.2 完整窗口
- 默认 1100×720（最小 900×600）；系统标题栏隐藏（自绘顶部 8px 拖拽条），左栏 190，主区 padding 20 24 0。
- 左栏：品牌（陶土方形图标 + 「桌面待办」+ v1.0）、可滚动导航区（视图列表：图标 + 名称 + 计数，选中项暖灰底、墨色文字；项目：8px 彩色圆点；标签：# 图标）、固定 footer（只保留设置）。导航区超出高度时只滚动中部，品牌与 footer 固定，设置始终可见可点。项目、标签的分区标题最右侧各有一个 pencil 管理入口。
- 主区：标题「今天」29px 衬线；日期副行 11px；右侧只保留进度环 40px + 「收起到挂件」「收起到胶囊」两个 30×30 图标按钮 + 陶土「新建」按钮（**搜索入口不重复**：仅筛选行右侧放大镜与 `/` 快捷键；设置仅左栏底部入口）；筛选行（全部/标签/日期/优先级 + 关键词搜索）；分组标题「待办 4」「已完成 2」；底部长输入框（同款）与 footer。
- 三态互斥：完整窗口打开时隐藏桌面形态（挂件/胶囊），关闭后回到进入前的桌面形态；标题行两个图标按钮可直接把完整窗口切换到挂件或胶囊。

### 4.3 编辑任务弹窗
- 居中弹窗，默认 460 宽、wide 502；不采用右侧抽屉（会与 08 的模态契约冲突）。字段如下：
  标题 input / 备注 textarea / 标签 chips + 新增 / 日期时间 + 优先级 / 链接列表（图标 + 名称 + 路径 + 打开 + 删除）/ 拖拽区 / 底部：删除（左，危险色文字）+ 保存（右，陶土主按钮）。
- 拖拽区：虚线 1px `--hairline`、圆角 12、高 ~110，文案「把文件 / 文件夹拖到这里」+「或粘贴路径、UNC 共享路径、网址」。

### 4.4 筛选浮层
- 宽 320，圆角 12，浮层阴影 + 箭头指向触发 chip；从触发点生长（250ms / 关闭 120ms）。
- 内容：状态段控（待办/已完成/全部）→ 日期 chips → 标签 chips（多选）→ 优先级 chips → 关键词输入 → footer：重置（幽灵）+ 应用（陶土）。
- 选中 chip：陶土浅底 `--accent-soft` + 陶土文字，不用实心填充。

## 5.1 弹窗（模态）交互规则

- **关闭方式只有显式操作**：右上角 X、底部「取消」、主按钮「保存」，以及 Esc。
- **点击遮罩层不关闭弹窗**：避免误触遮罩丢掉正在编辑的标题/备注/链接。
- 弹窗打开时，背景滚动锁定、键盘焦点进入弹窗；Esc 关闭与 X 等价。
- 浮层（筛选、下拉）不属于模态：点击外部关闭保持不变。

## 5.2 日期时间选择器（自定义，claude 风格）

**所有日期/时间输入一律用自绘选择器，禁止使用浏览器原生 `datetime-local` / `date` 控件。** 共三处入口，共用同一组件：

1. 编辑任务弹窗 · 日期与时间
2. 筛选浮层 · 指定日期（date 模式，无时间行）
3. 输入框「日期」浮层 · 指定（datetime 模式）

字段按钮（dp-field）：

- 高 30px，1px `--hairline` 边，圆角 10，暖白底；左侧 calendar 图标 13px，右侧 chevron 12px。
- 空值文案「选择日期时间 / 选择日期」，颜色 `--faint`；有值时显示「11月25日 周三 09:00」（date 模式只到日「11月25日 周三」）。

弹层（#dpPop）：

- 宽 288px，内边距 12px 12px 10px，圆角 14，背景 `--card`，1px `--hairline`，阴影 `--shadow-pop`，z-index 190。
- 定位：优先出现在触发按钮下方；下方空间不足翻到上方；四周距视口边至少 12px。
- 结构：月份头（‹ 2026年11月 ›，衬线 14.5px）→ 周一开头的 6×7 日历 → **时间行（一行内：标签「时间」+ 时/分输入 34×26 + ⌄ 选择按钮 + 快捷 chips（动态取 2 个）靠右）** → footer「清除 … 取消 / 确定」。点 ⌄ 在时间行下方展开「小时 / 分钟」两列列表（面板总高不超出视口，必要时整体上翻），选中项陶土浅底，展开时自动滚到当前值。
- 日历：单元格 28px、圆角 8；非本月日期 `--faint`；今天用陶土色 1px 内描边；选中日陶土实底 + 白字。日期模式（筛选）不显示时间行与快捷 chips。
- 时间行（输入 + 选择两种交互并存）：① **输入**——时/分可直接键入（点击聚焦、输入两位数字，超出范围自动落到 0–23 / 0–59），**点击输入框不会关闭选择器**；② **选择**——点时间行右侧 ⌄ 展开「小时 00–23 / 分钟 00–59」两列列表，点某一项即写回输入框并高亮，再点 ⌄ 收起；快捷 chips 与时间行同一行、靠右，**固定只显示 2 个**，点击直接设定。只有点选择器外部、取消、确定或 Esc 才关闭。
- datetime 模式默认时间：今天 18:00（若已过，取下一个未来半点）；无选中日期时确定 = 今天。
- **过去时间不可选**：datetime 模式下，今天之前的日期 `disabled` 且置灰；选中今天时，早于当前小时的小时 `disabled`，当前小时下早于当前分钟的值 `disabled`（`date` 模式的筛选日期不受此限）。键入路径输入了过去时间时，点「确定」校验拦截并 toast「不能选择当前时间之前」，选择器保持打开。
- **快捷时间（2 个）按常用度动态生成**：每次保存任务时记录实际到期时刻（`ui.timeUsage`，最多保留 16 个键，含次数与最近使用时间）。取使用次数 ≥ 2 的时间，按次数降序、同次数按最近使用降序，取前 2 个；不足时用 09:00 / 12:00 / 18:00 补足；选中日期为今天时过滤已经过去的时间，不够 2 个再用今天的未来半点补齐。

状态与交互：

- hover `--hover` wash；点击日期为选中，点「确定」才写回字段（筛选/输入框浮层写回后立即生效并关闭）。
- 「清除」立即清空字段并返回空态文案（筛选清除日期条件）。
- Esc 只关选择器（下层弹窗保持打开）；点遮罩同样只关选择器、不关弹窗（见 5.1）；点选择器外部关闭。
- 动画：`dpIn` 0.16s 从触发点生长（`--ease-dp`）；`prefers-reduced-motion` 同全局降为 0.01ms。精确值见 08 §3.9。

## 5.3 项目 / 标签删除与管理

**行内删除（沿用）**
- 入口：左栏项目、标签行 **悬停时行尾出现删除图标**（trash，13px，`--muted`，hover 转 `--accent-deep`）；行内计数在悬停时隐藏，避免与图标重叠。
- 点击后：该实体关联任务数 > 0 时先弹「删除二次确认」；关联任务为 0 时直接删除。确认后顶部 toast「已删除项目/标签「名称」」并带「撤销」，撤销恢复原顺序、原任务归属与原导航位置。
- 删除项目：其下任务的 `projectId` 置空（显示「无项目」）；删除标签：从所有任务的 `tagIds` 中移除。
- 删除的正好是当前视图：自动切回「今天」。
- 项目/标签为空（0 任务）也可删除；「重置演示」可整体恢复种子数据。

**管理弹窗（v1.6）**
- 入口（两个层级）：① 设置 →「项目与标签」行右侧「管理」按钮：打开完整管理弹窗，同时管理项目与标签（与旧版行为一致）；② 左栏「项目」「标签」分区标题最右侧各有一个 pencil 图标：只打开对应单项的管理弹窗。管理弹窗关闭后，从设置进入的返回设置，从侧栏进入的直接关闭。
- 尺寸：完整弹窗 `width: min(468px, 94vw)`；单项弹窗 `.manage-scoped` 为 `width: min(424px, 94vw)`。标题按入口变化：「管理项目与标签」（设置入口）/「管理项目」/「管理标签」；副标题「重命名、删除或新建」。body 只渲染当前范围对应的段（完整弹窗为「项目」「标签」两段），各自列出：色点/标签图标 + 名称 + N 项待办 + 行尾「重命名 / 删除」操作（行悬停显示）。
- 新建：段底「+ 新建项目 / 标签」就地展开输入框 + 创建/取消；重名拒绝并 toast「已有同名项目「X」」，空名拒绝；创建成功后侧栏与弹窗同步，输入关闭。
- 帮助文案按范围切换：完整弹窗说明项目/标签两种删除后果；单项弹窗只说明当前类型。
- 重命名：行内就地展开输入框（预填原名，全选）+ 保存/取消；Enter 保存、Esc 取消；与现有项重名（排除自身）拒绝；成功后 toast「已重命名为：X」。
- 删除：与行内删除同一条规则——关联任务数 > 0 时弹删除确认，0 任务直接删除；删除后弹窗行立即消失，保留 toast 撤销。
- 关闭：底部「完成」或右上 X；点击遮罩不关闭（同 5.1）。从设置入口打开时，关闭后回到设置；Esc 在行内编辑状态下先取消编辑，否则同样返回设置。
- 动效：`.modal` 默认不带动画，仅首次打开时加 `.enter` 播放 `modalIn`（240ms），`animationend` 后移除；**弹窗内原地重绘（点项目/标签/优先级/日期 chip、管理弹窗增删改）只替换内容，不重播入场动画、不整体闪烁**，并保留 `.modal-body` 的 scrollTop。

**删除二次确认（v1.5，仅关联任务 > 0 时出现）**
- 入口：管理弹窗内每行的删除按钮、左栏项目/标签行的悬停删除，共用同一个确认流程。
- 判定口径：关联任务数 = 该项目/标签下所有任务（含已完成）；显示「待办 P · 已完成 D」。
- 尺寸与结构：`width: min(424px, 92vw)`，`role="alertdialog"`；标题「删除项目/标签「名称」？」；正文上方浅陶土色警示块（垃圾桶图标 + 统计），下方说明删除后任务的处理方式；底部「取消」+「删除项目/删除标签」；右上 X 等同取消。
- 文案：项目「该项目下还有 N 项任务（待办 P · 已完成 D）。」「删除项目不会删除任务，任务会变成「无项目」；删除后可在底部提示里撤销。」；标签「该标签下还有 N 项任务（待办 P · 已完成 D）。」「删除标签不会删除任务，只会去掉这个标签；删除后可在底部提示里撤销。」
- 取消 / Esc / X：不删除。从管理弹窗发起则回到管理弹窗；从左栏发起则关闭确认浮层。
- 确认：删除并保留 toast 撤销；若从管理弹窗发起，弹窗原地刷新并保留滚动位置。

## 5.4 进度环（完成度）

- 三种尺寸：主视图 40px、挂件 34px、胶囊 26px；环宽统一 3px，底环 `--ring-track`，进度弧 `--accent`，从 12 点方向顺时针。
- 环内文案：整数百分比 + 「%」，颜色 `--ring-label`；数字与弧的视觉间隙不少于 4px（40px 环约 6px，34px 约 4.8px，26px 约 3.9px）。
- 100% 时数字变宽：自动切 `wide` 变体，数字再缩一档，保证与 2 位数（29% 等）相同的四周间隙，不贴环、不溢出。
- 实现约定：中文 Windows 的 Chromium 会把 <12px 字号强制渲染为 12px，所以环内数字基准字号固定 12px，再用 `transform: scale()` 做视觉缩放（40px：2 位数 .66 / 100% .52；34px：.568 / .448；26px：.424 / .334）。正式应用沿用同一基准 + scale，保证渲染一致。
- 数字变化 160ms tween，不闪烁；全部完成时环 100% 且保持留白。

## 5.5 滚动条（claude 风格）

- 全应用统一用自绘细滚动条，**不出现系统原生带上下箭头的滚动条**；轨道透明，只留滑块，四角透明。
- 尺寸：标准 9px（任务列表、编辑弹窗、输入框、挂件正文）；浮层内小列表 6px（时间选择的小时/分钟列）。
- 滑块：暖灰 `#D9D2C3`，圆角 999px，两端各 2px 透明边框（`border:2px solid transparent; background-clip:padding-box`）形成内缩细条；最短 32px；悬停 `#C6BDA9`，按下 `#B5AA94`。
- 隐藏 `::-webkit-scrollbar-button`（上下箭头）与 `::-webkit-scrollbar-corner` 底色；Firefox 同步用 `scrollbar-width: thin` + `scrollbar-color: #D9D2C3 transparent`。
- **输入框**：默认 1 行、随内容增高；到最大高度 110px（约 5 行）后在输入区内部滚动，滚动条就是标准 9px 滑块、轨道隐形；**不为滚动条预留常驻槽位**，避免输入过程中文字宽度跳动。
- textarea 自动换行，不出现横向滚动条；横向滚动条仅可能出现在特殊内容块，尺寸与颜色同标准。
- 深色主题（若启用）：滑块 rgba(255,255,255,.18)，悬停 .26，轨道仍透明。

## 5.6 逾期判定与展示

- **判定**：`due < now` 即逾期（按时间戳比较，**同一天内已过时间也算逾期**，不再按「日」判断）。
- **任务行元信息**：同日逾期显示「今天 10:00 · 已逾期 7 小时」（不足 1 小时显示分钟，如「已逾期 20 分钟」）；跨日逾期保留「逾期 1 天」；「已逾期」用 `--accent-deep`，与时间同一行。
- **同步范围**：顶栏「N 项逾期」、左栏「已逾期」计数、胶囊摘要、进度环、逾期排序全部用同一判定；「今天」视图包含同一天内已过时间的待办。
- **默认时间**：新建/快速添加的默认到期时间不得早于当前时刻（今天 18:00 已过则取下一个未来半点），从入口上避免一创建就逾期。

## 6. 动效（必须按数值实现）

| Token | 时长 | 用途 |
|-------|------|------|
| instant | 80ms | 按下反馈 scale(.97) |
| feedback | 120ms | hover wash、按钮颜色、chip 选中 |
| reveal | 120ms | 浮层关闭、收起动画 |
| surface | 150ms | 面板/卡片阴影与透明度 |
| open | 250ms | 筛选浮层从触发点生长、抽屉滑入 |
| enter | 320ms | 新任务行浮入（高度展开 + 透明度，spring(0.34,1.56,0.64,1)） |
| exit | 120ms | 删除/完成淡出 |
| bounce | 350ms | 发送按钮回弹、进度环数字滚动 |

- 勾选：圆圈 160ms 填充陶土 → 白勾 120ms 描边 → 整行 120ms 淡出 → 折叠进「已完成」（高度动画 250ms）。
- 减少动态：`prefers-reduced-motion` 时全部降为 0.01ms；不做常驻循环动画（逾期呼吸用 2s 的轻微透明度变化，可选）。
- 列表新增：从输入框位置向上浮入；删除：向左 8px + 淡出 120ms。

## 7. 图标

- 统一 16×16 线性图标，1.5px stroke，圆角端点，颜色继承 currentColor；建议 Lucide 图标集（npm `lucide-react`）。
- 需要的图标：inbox、sun(今天)、alert(逾期)、calendar、check-circle、tag、flag、clock、folder、globe(网页)、search、sliders、plus、pin、minus、chevron、dots、trash、file、arrow-up、x。

## 8. 可访问性

- 键盘可达：Tab 顺序 = 左栏 → 主区 → 输入框；项目/标签分区右侧的 pencil 管理入口可 Tab 聚焦并 Enter 打开；勾选框 Space 切换；Esc 关闭浮层/面板。
- 焦点环：墨色 3.5px 半透明 halo（不是蓝色 outline）。
- 对比度：正文 ≥ 4.5:1；弱文字 ≥ 3:1。
- 所有图标按钮有 `aria-label`；动效支持 reduced-motion；字号允许系统缩放。
- 不使用纯颜色单独表达状态：逾期同时有文字、优先级同时有文字（高/中/低）。
