# 05 · 任务拆解与实施顺序

> 按里程碑 M0–M6 顺序实施；里程碑是一次性交付内部的执行清单，不是分批交付节点。每项完成即对照当前 `../design/app/` 与 `../design/app-*.png` 状态截图自检，自检通过继续下一项，直到 M6 完成。估算是给「一个 agent + 用户验收」的节奏，不是硬指标。

## M0 · 脚手架与三窗口骨架（约 1 天）

先做 UI 基座：把 `../design/ui/tokens.css` 原样复制到 `src/renderer/src/styles/tokens.css`，接入字体、reset、滚动条工具类；之后所有组件只能 `var(--token)`。详见 08 §1/§6。

1. `pnpm create electron-vite`（或 electron-forge + vite），TS + React；确认 `pnpm dev` 可启动。
2. 主进程创建三个窗口：Widget（352 宽、frame:false、置顶、skipTaskbar）、Manager（1100×720、frame:false）、Capsule（284×54，可先合并进 Widget 视图）。
3. preload 暴露最小 API（ping / getPathForFile / 窗口控制）；确认 contextIsolation 生效。
4. electron-builder 出 portable exe 跑通（此时是空壳）。
**验收**：开发态与打包后都能启动、三窗口能显示、无 Node 泄漏到渲染层。

## M1 · 数据层（约 1 天）
1. `db.ts`：连接、WAL、迁移框架、schema（03 文档 DDL）。
2. repo：tasks CRUD + toggle、tags/projects、links、views、settings；全部事务化。
3. `filterSql.ts`：五维筛选 + 排序；单元测试（Vitest）：今天/逾期/标签/优先级/关键词边界。
4. seed 脚本导入 `resources/seed.json`（仅开发）；导出/导入 JSON。
**验收**：重启数据不丢；筛选结果与预期一致；单测通过。

## M2 · 桌面挂件（约 2 天，优先做，因为这是主入口）
1. 挂件 UI：标题「今天」+ 日期 + 进度环 + 图钉/收起；待办分组；已完成折叠；底部输入框；footer。
2. 勾选交互：160ms 填充 + 划线 + 折叠进已完成；取消完成。
3. 输入框：回车新增；识别「今天/明天 10:00/高/低」为 chips（先做基础解析，可点掉）。
4. 拖动 + 位置记忆 + 多显示器夹取；置顶开关；透明度。
5. 收起为胶囊：284×54，显示今天条数与最近任务；双击展开；Esc 收起。
6. 双击空白新增；链接点击（先只做网页+文件夹打开）。
**验收**：对着 [../design/app-desktop.png](../design/app-desktop.png) 与 `../design/app/` 的挂件区域 1:1 对照；勾选动画手感接近；关掉再开位置不丢。并逐项通过 [08 §2.2/§3.2/§3.3/§3.5/§3.6/§3.11](08-UI-ENGINEERING-SPEC.md) 的组件状态。

## M3 · 完整窗口（约 2 天）
1. 左栏：视图计数、项目、标签、选中态、底部状态。
2. 主区：标题/日期/进度环/新建；筛选行；分组列表；底部长输入框。
3. 筛选浮层五维 + 已选数量 + 重置；「保存为桌面视图」+ 挂件下拉切换。
4. 编辑任务面板：字段齐全；删除/保存；新建任务默认落到当前视图。
5. 空状态、加载态、错误 toast。
**验收**：对照 `../design/app/` 当前页面与 `../design/app-manager.png`、`../design/app-filter.png`、`../design/app-editor.png` 等状态截图；筛选组合正确；两窗口数据实时同步。并逐项通过 [08 §2.3/§3.7/§3.8/§3.9/§3.13](08-UI-ENGINEERING-SPEC.md)。

## M4 · 链接与拖拽（约 1.5 天）
1. opener.ts 安全打开（http/https / 路径 / UNC / 拒绝危险协议）。
2. 编辑面板链接列表：添加（粘贴）、打开、删除、自定义显示名。
3. 拖拽文件/文件夹/URL 到编辑面板或任务行；UNC 文本粘贴。
4. 失效检测 + 重新定位 + 删除；打开失败 toast。
5. 类型识别测试：`C:\...`、`\\server\share\...`、含空格/中文、长路径、`file:///C:/...`。
**验收**：真实共享盘/本地目录点开即开；坏链接有清晰提示不崩。

## M5 · 托盘 / 快捷键 / 设置 / 自启（约 1 天）
1. 托盘图标 + 菜单（显隐、快速添加、打开窗口、开机自启勾选、退出）。
2. 全局快捷键（Ctrl+Shift+Space / Alt+H / Alt+1..5）+ 设置开关；注册失败提示。
3. 关窗只收进托盘；单实例；`--silent` 启动。
4. 设置面板：置顶、透明度、开机自启（默认关）、数据目录、导出/导入、关于。
5. 开机自启接 `app.setLoginItemSettings`，与设置项双向同步。
**验收**：托盘全链路可用；重启电脑自启开关生效且静默；快捷键不与其他软件冲突时可改。

## M6 · 打磨与打包（约 1 天）
1. 动效逐项对齐 08 §1.5；reduced-motion 全局 0.01ms。
2. 键盘操作、焦点环、aria-label；空状态文案。
3. 时间刷新：每分钟重算逾期（同日已过时间也算），跨日重算今天/即将到期。
4. 打包 portable + NSIS；写 README（安装、SmartScreen 说明、数据目录、备份）。
5. 按 [07-ACCEPTANCE.md](07-ACCEPTANCE.md) 全量验收 + 10 步冒烟。
**验收**：验收清单全绿；exe 在干净目录可运行；数据目录/备份可找到；按 08 §5 + 07-G 全量视觉对照。

## 给实施者的提示
- 先做「能用的挂件」再补完整窗口，用户最早能感知价值。
- 每一步都拿当前 `../design/app-*.png` 状态截图对照；颜色/字号/间距只从 tokens.css 取，组件尺寸/状态按 08。
- 不要引入任何网络请求、遥测、云依赖；不要做系统通知。
- 数据层与 UI 分离，repo 可单测；不要为了快把 SQL 拼进组件。
