# 01 · 需求规格（PRD）

> UI 实施契约：08-UI-ENGINEERING-SPEC.md + ../design/ui/tokens.css；本文只定义功能需求，不重复视觉细节。

## 1. 背景与目标

日常办公中，任务散落在聊天、邮件、共享盘和网页里。用户需要一件事：**桌上一直能看到今天要做什么，点一下任务上的链接就回到工作现场，勾一下就算完成**，不打开重量级项目管理软件。

目标：
- 常驻桌面但不打扰（挂件为主入口，可收起为胶囊）。
- 3 秒完成一次「新增 / 勾选 / 打开链接」。
- 数据 100% 本地，断网、内网环境可用。

## 2. 用户场景

1. 早上开机，挂件已经在桌面右侧显示今天 4 项任务；扫一眼知道有 1 项逾期。
2. 正在改图纸，需要打开 `\\fileserver\项目A\IEOP-模具图纸`：点任务下的文件夹链接，资源管理器直接打开。
3. 会议中记一条「回复设计评审意见」，回车保存；挂件出现新任务。
4. 临时只想看「采购 + 高优先级 + 本周」：桌面筛选浮层选完，存成桌面视图，挂件标题下拉切换。

## 3. 范围

### MVP 必须做
- 三形态：桌面挂件（主）、完整窗口（管理）、收起胶囊（极简常驻）。
- 任务：新增 / 编辑 / 删除 / 勾选完成 / 取消完成。
- 字段：标题（必填）、备注（纯文本）、标签（多选）、优先级（高/中/低/无）、日期时间（可选）、多条链接。
- 链接：网页、文件夹、文件、UNC；点击用系统默认程序打开；拖拽/粘贴添加；失效可重新定位。
- 筛选：状态、日期、标签、优先级、关键词五维组合；保存为桌面视图并在挂件切换。
- 视图：收件箱（无日期且无项目）/ 今天 / 已逾期 / 即将到期 / 已完成；左栏项目、标签，两者分区标题右侧各有单项管理入口；设置中「项目与标签」可整体管理。
- 托盘、全局快捷键、单实例、位置记忆、开机自启设置项。
- 设置：置顶、透明度、开机自启、项目与标签管理、数据目录展示、导出备份。

### 明确不做（非目标）
- 云同步 / 多端 / 多人协作 / 账号体系。
- Windows 系统通知、声音提醒、闹钟。
- 手机端、Web 端。
- 子任务、重复任务、看板、甘特图、番茄钟。
- 附件上传（只保存本地路径，不复制文件）。
- 富文本备注（纯文本 + 自动识别 URL）。
- 自动更新、代码签名（会触发 SmartScreen 提示，README 说明即可）。

## 4. 功能需求

### FR-1 桌面挂件（主入口）
- 1.1 启动后默认显示挂件，位于主屏右侧，尺寸 **宽 352px**、高度按内容自适应（最大 520px，超出滚动）。
- 1.2 无边框、圆角 16、带浮起阴影；默认置顶（可设置关闭）。
- 1.3 可拖动（标题区域拖拽），记住位置；重启后恢复。与胶囊共用同一位置记忆。
- 1.4 多显示器：位置按屏幕相对坐标保存，显示器拔插后自动夹回可见区域。
- 1.5 默认「今天」视图；标题下显示 `11月21日 周六 · 1 项逾期`。
- 1.6 任务行：勾选框、标题、时间、链接；点击勾选框完成（160ms 动画后折叠进「已完成」）。
- 1.7 底部默认显示「+ 添加任务」小按钮，点击展开输入框并聚焦；输入标题回车保存，默认无日期（即「今天」）；支持输入「明天 10:00 / 高」自动识别为字段（可点掉）；Esc / 点击外部 / 提交后收起输入框。
- 1.8 底部展示 `2/6 已完成`。
- 1.9 双击空白处快速新增；双击标题打开完整窗口；Esc 先收起输入框（若展开），否则收起为胶囊；悬停显示图钉/收起按钮。
- 1.10 挂件内可直接点链接打开（网页/资源管理器）。
- 1.11 挂件内点击任务打开**桌面级编辑弹窗**（独立透明窗口，550 宽 = 502 弹窗 + 24×2 内边距，按内容高度居中在挂件所在显示器）；不塞进 352 宽挂件窗口；X / 取消 / 保存 / Esc / 删除后关闭，挂件保持原样。

### FR-2 完整窗口
- 2.1 尺寸默认 1100×720，可缩放，位置/尺寸记忆。
- 2.2 左栏：收件箱、今天、已逾期、即将到期、已完成（带计数）；项目；标签。导航区（视图+项目+标签）超出高度时只滚动中部，品牌与底部固定；底部只保留「设置」，设置始终可见。项目、标签分区标题最右各有一个 pencil 单项管理入口。收件箱只显示「无日期且无项目」的任务（标签不影响），计数同口径；有项目但无日期的任务只出现在项目视图。
- 2.3 主区：视图大标题 + 日期 + 逾期提示 + 进度环 + 「收起到挂件」「收起到胶囊」两个图标按钮 + 新建按钮；筛选行；分组「待办 N / 已完成 N」；底部同款输入框。
- 2.4 完成任务划线并折叠进「已完成」，可展开、可取消完成。
- 2.5 点击任务打开编辑面板（标题/备注/标签/日期/优先级/链接/删除/保存）；完整窗口内为原地模态（460/wide 502）。
- 2.6 项目 / 标签管理：两个入口——设置 →「项目与标签」→「管理」打开完整管理弹窗（项目+标签）；左栏项目/标签分区标题右侧 pencil 打开对应单项管理弹窗。均可新建、行内重命名、删除；重名拒绝、空名拒绝；删除项目后任务保留（projectId 置空），删除标签从任务移除关联；删除时有关联任务（含已完成）先二次确认，无关联任务直接删除；两者均保留 toast 撤销。
- 2.7 三态互斥：桌面挂件、完整窗口、胶囊任一时刻只存在一种可见形态；打开完整窗口时隐藏桌面形态，关闭完整窗口后回到进入前的桌面形态（挂件或胶囊）。
- 2.8 位置基准：挂件与胶囊共用位置记忆；切换形态时按窗口所在象限保持「就近角」屏幕坐标不变（默认右上；左上/右上/左下/右下自适应）。
- 2.9 侧栏 footer 固定：中部导航区独立滚动，底部固定「使用说明」「设置」两个入口（上为使用说明，下为设置），不随导航滚动。

### FR-3 任务与链接
- 3.1 标题必填；保存时 trim；重复标题允许。
- 3.2 日期支持：今天、明天、本周、逾期、自定义日期时间。
- 3.3 优先级：高/中/低/无，列表用不同颜色小旗标。
- 3.4 链接条目：类型自动识别（http/https → 网页；盘符路径/UNC/文件夹 → 本地；文件扩展名 → 文件）；每条可自定义显示名——编辑弹窗内点击链接标题即可行内编辑，留空回退自动名称（URL 去协议截断、路径取最后一段）。
- 3.5 打开规则（安全）：仅允许 http/https 用默认浏览器；本地路径先校验存在再用资源管理器打开；**禁止** file://、javascript:、shell 命令拼接。
- 3.6 失效处理：打开失败弹提示「找不到该位置」，提供「重新选择」「删除链接」；不静默失败。
- 3.7 拖拽：文件/文件夹拖入编辑面板或任务行 → 自动生成链接；拖入网址 → 生成网页链接；粘贴 UNC 路径 → 生成本地链接。
- 3.8 路径保存为绝对路径；含中文、空格、长路径需正常处理。
- 3.9 空链接提示：编辑面板无链接时显示「还没有链接」，拖拽区文案「把文件 / 文件夹拖到这里，或粘贴路径」+ 副文案「拖入后自动识别为文件、文件夹或网址」，两处不重复。

### FR-4 筛选与桌面视图
- 4.1 五维：状态（待办/已完成/全部）、日期（今天/明天/本周/逾期/自定义）、标签（多选，OR）、优先级（多选）、关键词（标题+备注，LIKE）。
- 4.2 组合即时生效，筛选按钮显示已选数量；重置只清本次筛选。
- 4.3 可保存当前筛选为「桌面视图」（命名/重命名/删除）；挂件标题旁下拉切换；完整窗口与挂件共享。
- 4.4 筛选条件不跨启动保留（启动回到上次视图，但未保存的临时筛选清空）。

### FR-5 托盘与快捷键
- 5.1 托盘图标常驻；点击显示/隐藏挂件；双击打开完整窗口。
- 5.2 托盘菜单：显示/隐藏挂件、快速添加、打开完整窗口、开机自启（勾选）、退出。
- 5.3 全局快捷键（可在设置中关闭）：`Ctrl+Shift+Space` 快速添加、`Alt+H` 显隐挂件、`Alt+1..5` 切视图。
- 5.4 窗口内：`Ctrl+N` 新建、`Esc` 收起、`Ctrl+F` 搜索。
- 5.5 关闭完整窗口后回到进入前的桌面形态（挂件或胶囊），应用继续在托盘常驻；退出仅从托盘「退出」。
- 5.6 快捷键注册失败时用**应用内提示弹窗**（独立 472 宽透明窗口 + 自建 NoticeModal + 警示块 + 快捷键清单 + 「知道了」），不使用系统原生对话框；窗口加载失败 2.5s 内才回退原生提示。数据库不可用/重建提示同样走应用内弹窗。

### FR-6 设置
- 6.1 置顶开关、挂件透明度（100/90/80%）、开机自启（默认关）、全局快捷键开关。
- 6.2 展示数据目录，可「打开所在文件夹」；导出 JSON 备份 / 导入（导入前提示覆盖）。
- 6.3 设置持久化在 SQLite settings 表。
- 6.4 「关于」：版本、纯本地说明。
- 6.5 「项目与标签」行：右侧「管理」按钮打开完整管理弹窗，可新建/重命名/删除；单项管理见 FR-2.6。
- 6.6 使用说明：完整窗口左栏 footer 固定「使用说明」入口（在「设置」之上），打开应用内说明弹窗（wide），只读，覆盖三形态、添加与编辑、链接、筛选与桌面视图、快捷键、数据与设置。

### FR-7 数据与稳定性
- 7.1 SQLite（WAL）；位置 `%APPDATA%\DesktopTodo\data.db`。
- 7.2 单实例：重复启动只唤起已有窗口。
- 7.3 数据库异常（损坏/权限）启动时提示并可重建；写操作事务化。
- 7.4 时间刷新：每分钟重算逾期（同一天内已过时间也视为逾期）；日期变化时「今天/即将到期」自动重算，跨日不丢状态。

## 5. 边界与异常

| 场景 | 期望行为 |
|------|----------|
| 链接文件被移动/删除 | 打开时检测不到 → 提示重新定位或删除，不崩溃 |
| UNC 共享盘不可达 | 打开前异步探测超时 800ms，提示「无法访问，可能不在内网」 |
| 路径含中文/空格/长路径 | 正常保存与打开（\\?\ 前缀可选） |
| 多显示器 | 位置夹回主屏可见区域，不出现窗口消失 |
| DPI 125%/150% | 布局不糊、不错位；窗口尺寸按 DIP |
| 无网络启动 | 完全正常（无任何网络请求） |
| 数据库被占用/损坏 | 提示并提供重建；旧库备份为 data.db.bak |
| 系统只有 4GB 内存 | 挂件常驻内存 < 300MB |

## 6. 非功能指标

- 冷启动到挂件可见 < 2s（SSD）。
- 勾选反馈 < 50ms；新增任务从回车到列表出现 < 120ms。
- 1000 条任务下列表滚动流畅（必要时虚拟列表）；搜索 < 300ms。
- 安装包 < 120MB；便携 exe 可直接运行；无需管理员权限。
- 支持 Windows 10 1903+ / Windows 11 x64。
