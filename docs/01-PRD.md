# 01 · 需求规格（PRD）

> UI 实施契约：08-UI-ENGINEERING-SPEC.md + ../design/ui/tokens.css；本文只定义功能需求，不重复视觉细节。

## 1. 背景与目标

日常办公中，任务散落在聊天、邮件、共享盘和网页里。用户需要一件事：**桌上一直能看到今天要做什么，点一下任务上的链接就回到工作现场，勾一下就算完成**，不打开重量级项目管理软件。

目标：
- 常驻桌面但不打扰（挂件为主入口，可收起为胶囊）。
- 3 秒完成一次「新增 / 勾选 / 打开链接」。
- 数据 100% 本地，断网、内网环境可用。

## 2. 用户场景

1. 早上开机，挂件已经在桌面右侧显示今天 4 项任务；扫一眼知道有 1 项逾期。
2. 正在改图纸，需要打开 `\\fileserver\项目A\IEOP-模具图纸`：点任务下的文件夹链接，资源管理器直接打开。
3. 会议中记一条「回复设计评审意见」，回车保存；挂件出现新任务。
4. 临时只想看「采购 + 高优先级 + 本周」：桌面筛选浮层选完，存成桌面视图，挂件标题下拉切换。

## 3. 范围

### 平台范围与系统要求

| 平台 | 系统要求 | 安装形态 | 交付物 |
| --- | --- | --- | --- |
| Windows | Windows 10 1903+ / Windows 11（x64） | 便携版 / NSIS 安装版；未签名，首次运行有 SmartScreen 提示 | `DesktopTodo-<version>-portable.exe`、`DesktopTodo-<version>-setup.exe` |
| macOS | macOS 12+，Apple 芯片（arm64）；Intel 芯片 Mac 不在支持范围 | dmg 拖入「应用程序」；未签名未公证，首次打开需 Gatekeeper 放行 | `DesktopTodo-<version>-arm64.dmg` |

两平台功能对齐：三形态、任务/链接/筛选、托盘或菜单栏、全局快捷键、登录时启动、本地 SQLite、纯本地不联网；差异只在系统形态映射与本地路径口径（见下方「形态映射」与 03 §5）。Windows 10/11 的既有行为不因 macOS 版本改动。

### MVP 必须做
- 三形态：桌面挂件（主）、完整窗口（管理）、收起胶囊（极简常驻）。
- 任务：新增 / 编辑 / 删除 / 勾选完成 / 取消完成。
- 字段：标题（必填）、备注（纯文本）、标签（多选）、优先级（高/中/低/无）、日期时间（可选）、多条链接。
- 链接：网页、文件夹、文件、UNC（Windows）或绝对 POSIX 路径（macOS）；点击用系统默认程序打开；拖拽/粘贴添加；失效可重新定位。
- 筛选：状态、日期、标签、优先级、关键词五维组合；保存为桌面视图并在挂件切换。
- 视图：收件箱（无日期且无项目）/ 今天 / 已逾期 / 即将到期 / 已完成；左栏项目、标签，两者分区标题右侧各有单项管理入口；设置中「项目与标签」可整体管理。
- 托盘（macOS 为菜单栏图标）、全局快捷键、单实例、位置记忆、开机自启（macOS「登录时自动启动」）设置项。
- 设置：置顶、透明度、开机自启、项目与标签管理、数据目录展示、导出备份。

### 明确不做（非目标）
- 云同步 / 多端 / 多人协作 / 账号体系。
- 系统通知（Windows / macOS）、声音提醒、闹钟。
- 手机端、Web 端。
- 子任务、重复任务、看板、甘特图、番茄钟。
- 附件上传（只保存本地路径，不复制文件）。
- 富文本备注（纯文本 + 自动识别 URL）。
- 自动更新、代码签名与公证（Windows 会触发 SmartScreen、macOS 会触发 Gatekeeper 提示，README 说明即可）。

### 形态映射（Windows ↔ macOS）

| 能力 | Windows | macOS |
| --- | --- | --- |
| 常驻入口 | 托盘图标 | 菜单栏图标（状态栏模板图标，黑 + alpha，系统自动适配深浅色） |
| 常驻入口交互 | 单击显示/隐藏挂件，双击打开完整窗口；右键弹出动态菜单 | 左键单击弹出菜单：显示/隐藏挂件、快速添加、打开完整窗口、登录时启动、退出桌面待办 |
| 任务栏 / Dock | 挂件与胶囊 `skipTaskbar: true`，不占任务栏；完整窗口显示任务栏项 | Dock 默认隐藏；打开完整窗口时显示（可用 ⌘+Tab 切回），收起完整窗口后隐藏 |
| 应用菜单 | 无应用菜单（无边框自绘界面，Ctrl 快捷键） | 「桌面待办 / 编辑 / 窗口」应用菜单；⌘Q、⌘W、⌘M、⌘C/⌘V/⌘A/⌘Z 等标准项生效 |
| 全局快捷键 | Ctrl+Shift+Space、Alt+H、Alt+1..5 | 同一组按键注册（CommandOrControl 映射 ⌘、Alt 映射 ⌥）；界面文案显示 ⌘⇧Space、⌥H、⌥1–5 |
| 开机自启 | 设置项「开机自动启动」；登录项带 `--silent`，开机只进托盘 | 设置项「登录时自动启动」；写系统登录项，由登录项拉起时以 `wasOpenedAtLogin` 判定静默启动，只留菜单栏图标 |
| 桌面形态 | 挂件/胶囊透明无边框、`alwaysOnTop: 'floating'` | 相同；保留硬件合成（Windows 的软件合成内存策略不迁移） |
| 关闭完整窗口 | 拦截 `close` 改为隐藏，回到桌面形态，应用继续在托盘常驻 | 相同；完整窗口关闭即收起，Dock 随之隐藏 |
| 本地链接 | 盘符、UNC、`/cygdrive/...`（可选）、`file:///C:/...` 转本地路径 | 绝对 POSIX 路径（`/Users/...`、`/Volumes/...`）、本机 `file:///` URL；无 UNC 概念，Windows 盘符/UNC 判不支持 |

## 4. 功能需求

### FR-1 桌面挂件（主入口）
- 1.1 启动后默认显示挂件，位于主屏右侧，尺寸 **宽 352px**、高度按内容自适应（最大 520px，超出滚动）。
- 1.2 无边框、圆角 16、带浮起阴影；默认置顶（可设置关闭）。
- 1.3 可拖动（标题区域拖拽），记住位置；重启后恢复。与胶囊共用同一位置记忆。
- 1.4 多显示器：位置按屏幕相对坐标保存，显示器拔插后自动夹回可见区域。
- 1.5 默认「今天」视图；标题下显示 `11月21日 周六 · 1 项逾期`。
- 1.6 任务行：勾选框、标题、时间、链接；点击勾选框完成（160ms 动画后折叠进「已完成」）。
- 1.7 底部默认显示「+ 添加任务」小按钮，点击展开输入框并聚焦；输入标题回车保存，默认无日期（即「今天」）；支持输入「明天 10:00 / 高」自动识别为字段（可点掉）；Esc / 点击外部 / 提交后收起输入框。
- 1.8 底部展示 `2/6 已完成`。
- 1.9 双击空白处快速新增；双击标题打开完整窗口；Esc 先收起输入框（若展开），否则收起为胶囊；悬停显示图钉/收起按钮。
- 1.10 挂件内可直接点链接打开（网页 / 系统文件管理器；macOS 为访达）。
- 1.11 挂件内点击任务打开**桌面级编辑弹窗**（独立透明窗口，550 宽 = 502 弹窗 + 24×2 内边距，按内容高度居中在挂件所在显示器）；不塞进 352 宽挂件窗口；X / 取消 / 保存 / Esc / 删除后关闭，挂件保持原样。

### FR-2 完整窗口
- 2.1 尺寸默认 1100×720，可缩放，位置/尺寸记忆。
- 2.2 左栏：收件箱、今天、已逾期、即将到期、已完成（带计数）；项目；标签。导航区（视图+项目+标签）超出高度时只滚动中部，品牌与底部固定；底部只保留「设置」，设置始终可见。项目、标签分区标题最右各有一个 pencil 单项管理入口。收件箱只显示「无日期且无项目」的任务（标签不影响），计数同口径；有项目但无日期的任务只出现在项目视图。
- 2.3 主区：视图大标题 + 日期 + 逾期提示 + 进度环 + 「收起到挂件」「收起到胶囊」两个图标按钮 + 新建按钮；筛选行；分组「待办 N / 已完成 N」；底部同款输入框。
- 2.4 完成任务划线并折叠进「已完成」，可展开、可取消完成。
- 2.5 点击任务打开编辑面板（标题/备注/标签/日期/优先级/链接/删除/保存）；完整窗口内为原地模态（460/wide 502）。
- 2.6 项目 / 标签管理：两个入口——设置 →「项目与标签」→「管理」打开完整管理弹窗（项目+标签）；左栏项目/标签分区标题右侧 pencil 打开对应单项管理弹窗。均可新建、行内重命名、删除；重名拒绝、空名拒绝；删除项目后任务保留（projectId 置空），删除标签从任务移除关联；删除时有关联任务（含已完成）先二次确认，无关联任务直接删除；两者均保留 toast 撤销。
- 2.7 三态互斥：桌面挂件、完整窗口、胶囊任一时刻只存在一种可见形态；打开完整窗口时隐藏桌面形态，关闭完整窗口后回到进入前的桌面形态（挂件或胶囊）。
- 2.8 位置基准：挂件与胶囊共用位置记忆；切换形态时按窗口所在象限保持「就近角」屏幕坐标不变（默认右上；左上/右上/左下/右下自适应）。
- 2.9 侧栏 footer 固定：中部导航区独立滚动，底部固定「使用说明」「设置」两个入口（上为使用说明，下为设置），不随导航滚动。

### FR-3 任务与链接
- 3.1 标题必填；保存时 trim；重复标题允许。
- 3.2 日期支持：今天、明天、本周、逾期、自定义日期时间。
- 3.3 优先级：高/中/低/无，列表用不同颜色小旗标。
- 3.4 链接条目：类型自动识别（http/https → 网页；Windows 盘符/UNC 路径或 macOS 绝对 POSIX 路径/文件夹 → 本地；文件扩展名 → 文件）；每条可自定义显示名——添加链接时即可在「标题（可选）」输入；编辑弹窗内点击链接标题或路径进入行内编辑，可同时修改链接地址与标题，地址无效时拒绝并保持编辑，标题留空回退自动名称（URL 去协议截断、路径取最后一段）；仅改地址且标题此前为自动名称时，标题跟随新地址重算。
- 3.5 打开规则（安全）：仅允许 http/https 用默认浏览器；本地路径先校验存在再用系统文件管理器打开（Windows 资源管理器 / macOS 访达）；**禁止**直接打开 file: 协议（Windows 拒绝；macOS 的本机 `file:///` 先转成本地路径再按路径规则校验）、javascript:、shell 命令拼接。
- 3.6 失效处理：打开失败弹提示「找不到该位置」，提供「重新选择」「删除链接」；不静默失败。
- 3.7 拖拽：文件/文件夹拖入编辑面板或任务行 → 自动生成链接（Windows 资源管理器 / macOS Finder）；拖入网址 → 生成网页链接；粘贴 UNC 路径（Windows）或绝对 POSIX 路径（macOS）→ 生成本地链接。
- 3.8 路径保存为绝对路径；含中文、空格、长路径需正常处理。
- 3.9 空链接提示：编辑面板无链接时显示「还没有链接」，拖拽区文案「把文件 / 文件夹拖到这里，或粘贴路径」+ 副文案「拖入后自动识别为文件、文件夹或网址」，两处不重复。

### FR-4 筛选与桌面视图
- 4.1 五维：状态（待办/已完成/全部）、日期（今天/明天/本周/逾期/自定义）、标签（多选，OR）、优先级（多选）、关键词（标题+备注，LIKE）。
- 4.2 组合即时生效，筛选按钮显示已选数量；重置只清本次筛选。
- 4.3 可保存当前筛选为「桌面视图」（命名/重命名/删除）；挂件标题旁下拉切换；完整窗口与挂件共享。
- 4.4 筛选条件不跨启动保留（启动回到上次视图，但未保存的临时筛选清空）。

### FR-5 托盘 / 菜单栏与快捷键
- 5.1 托盘图标常驻（macOS 为菜单栏图标）；点击显示/隐藏挂件；双击打开完整窗口（macOS 菜单栏为左键单击弹出菜单，无双击语义，见 §3 形态映射）。
- 5.2 托盘菜单（macOS 为菜单栏菜单）：显示/隐藏挂件、快速添加、打开完整窗口、开机自启（勾选；macOS 文案「登录时启动」）、退出。
- 5.3 全局快捷键（可在设置中关闭）：`Ctrl+Shift+Space` 快速添加、`Alt+H` 显隐挂件、`Alt+1..5` 切视图。macOS 上同一组快捷键注册不变，界面文案显示 `⌘⇧Space`、`⌥H`、`⌥1–5`。
- 5.4 窗口内：`Ctrl+N` 新建、`Esc` 收起、`Ctrl+F` 搜索（macOS 文案为 `⌘N` / `⌘F`）。
- 5.5 关闭完整窗口后回到进入前的桌面形态（挂件或胶囊），应用继续在托盘/菜单栏常驻；退出仅从托盘/菜单栏菜单或应用菜单「退出」。
- 5.6 快捷键注册失败时用**应用内提示弹窗**（独立 472 宽透明窗口 + 自建 NoticeModal + 警示块 + 快捷键清单 + 「知道了」），不使用系统原生对话框；窗口加载失败 2.5s 内才回退原生提示。数据库不可用/重建提示同样走应用内弹窗。

### FR-6 设置
- 6.1 置顶开关、挂件透明度（100/90/80%）、开机自启（macOS 文案「登录时自动启动」，默认关）、全局快捷键开关。
- 6.2 展示数据目录，可「打开所在文件夹」；导出 JSON 备份 / 导入（导入前提示覆盖）。
- 6.3 设置持久化在 SQLite settings 表。
- 6.4 「关于」：版本、纯本地说明。
- 6.5 「项目与标签」行：右侧「管理」按钮打开完整管理弹窗，可新建/重命名/删除；单项管理见 FR-2.6。
- 6.6 使用说明：完整窗口左栏 footer 固定「使用说明」入口（在「设置」之上），打开应用内说明弹窗（wide），只读，覆盖三形态、添加与编辑、链接、筛选与桌面视图、快捷键、数据与设置。

### FR-7 数据与稳定性
- 7.1 SQLite（WAL）；位置：Windows `%APPDATA%\DesktopTodo\data.db`，macOS `~/Library/Application Support/DesktopTodo/data.db`。
- 7.2 单实例：重复启动只唤起已有窗口。
- 7.3 数据库异常（损坏/权限）启动时提示并可重建；写操作事务化。
- 7.4 时间刷新：每分钟重算逾期（同一天内已过时间也视为逾期）；日期变化时「今天/即将到期」自动重算，跨日不丢状态。

## 5. 边界与异常

| 场景 | 期望行为 |
|------|----------|
| 链接文件被移动/删除 | 打开时检测不到 → 提示重新定位或删除，不崩溃 |
| UNC 共享盘不可达（Windows） | 打开前异步探测超时 800ms，提示「无法访问，可能不在内网」 |
| Windows 盘符/UNC 路径在 macOS 粘贴 | 判为不支持并提示（要求网址、文件夹或本地文件路径）；不崩溃、不误开 |
| macOS 拖入 Finder 文件/文件夹 | 识别为绝对 POSIX 路径链接；真实 Finder 拖拽未人工验证（见 README 已知限制） |
| macOS 首次打开被 Gatekeeper 拦截 | 右键 → 打开 → 再点打开，或「系统设置 → 隐私与安全性 → 仍要打开」（README 说明） |
| 路径含中文/空格/长路径 | 正常保存与打开（Windows `\\?\` 前缀可选） |
| 多显示器 | 位置夹回主屏可见区域，不出现窗口消失 |
| DPI 125%/150% | 布局不糊、不错位；窗口尺寸按 DIP |
| 无网络启动 | 完全正常（无任何网络请求） |
| 数据库被占用/损坏 | 提示并提供重建；旧库备份为 data.db.bak |
| 系统只有 4GB 内存 | 挂件常驻内存 < 300MB |

## 6. 非功能指标

- 冷启动到挂件可见 < 2s（SSD）。
- 勾选反馈 < 50ms；新增任务从回车到列表出现 < 120ms。
- 1000 条任务下列表滚动流畅（必要时虚拟列表）；搜索 < 300ms。
- 安装包 < 120MB（macOS arm64 dmg 115.1 MiB）；便携 exe 可直接运行、dmg 拖入「应用程序」即可用；无需管理员权限。
- 支持 Windows 10 1903+ / Windows 11 x64；macOS 12+ Apple 芯片（arm64），Intel 芯片 Mac 不在支持范围。

## 7. 验收

功能逐条对照 [07-ACCEPTANCE.md](07-ACCEPTANCE.md)。
