## 1. 一句话

一个 Windows 桌面 TODO 小工具：**桌面挂件为主入口**，随时看见今天要做什么、随手勾；每条任务可以直接挂**网页链接、文件夹/文件路径（含 UNC 共享盘）**，点一下就打开对应位置；**纯本地、内网可用、不联网**。

## 2. 现在就可以体验（可交互原型 v1.0）

本机原型服务已在运行，直接用浏览器打开：

**http://127.0.0.1:8765/app/index.html**

打不开时：进入项目根下的 `design/`，双击 **启动原型.bat**（需 Node.js），或在该目录执行 `node server.mjs` 后再访问。

顶部控制条：**桌面 / 完整窗口 / 怎么玩 / 重置演示**。数据只存在浏览器 localStorage，不联网、不上传。

建议体验路径：

1. 桌面形态：勾掉一条任务 → 进度环和已完成数变化；拖动挂件换位置；点「收起」变胶囊，把胶囊拖到任意角落，刷新页面看它是否还在原位，再点胶囊展开
2. 切「完整窗口」：左栏逐个点 9 个视图；点标签/日期/优先级筛选；搜索「模具」
3. 底部输入框输入「明天 9:00 整理桌面文件 #设备」回车 → 日期/标签被自动解析
4. 点任意任务打开编辑弹窗：改标题、加标签、加日期、挂多个链接；点任务里的链接看「打开链接」说明；把文件拖进弹窗链接区
5. 双击列表空白处快速新建；删除任务后点 toast「撤销」
6. 设置里试透明度 90%/80%，或「重置演示」恢复 15 条演示数据

原型已覆盖：九视图与状态 Tab、五维筛选（标签/日期/优先级/关键词 + chips）、自然语言快速添加、任务编辑与多链接、拖拽文件/文件夹、挂件勾选/拖动/图钉/收起胶囊、**展开挂件与收起胶囊各自记忆最后位置，收起/展开状态也记忆（刷新/重启后恢复上次状态）**、完整窗口与挂件双向同步、删除撤销、设置、快捷键；**逾期按时间戳判断（同一天内已过时间也标红），日期时间选择器今天以前的日期与今天过去的时分置灰、快捷时间固定 2 个并按常用度动态生成**；收件箱按「无日期且无项目」口径，项目/标签支持在设置 →「项目与标签」→「管理」整体管理，或从侧栏项目/标签分区标题最右侧的 pencil 单项管理；弹窗内新建、行内重命名、删除，弹窗原地更新不闪烁；侧栏导航区可滚动，设置固定可见。

## 3. 已确认的决策（实施时不可擅改，除非用户重新确认）

| # | 决策 | 说明 |
|---|------|------|
| 1 | **纯本地单机** | 无账号、无云同步、无遥测、无任何网络请求；数据落本地 SQLite，内网可用 |
| 2 | **主入口 = 桌面挂件** | 无边框、可拖动、置顶可切、**尺寸按原型 352px 宽**、位置记忆、多显示器可用 |
| 3 | **挂件默认「今天」** | 打开即是今天视图；收起为右下角胶囊（显示今天条数/逾期数/进度） |
| 4 | **左栏保留** | 完整窗口仍有：收件箱 / 今天 / 已逾期 / 即将到期 / 已完成 + 项目 + 标签 |
| 5 | **筛选五维 + 桌面视图** | 状态、日期、标签、优先级、关键词；组合可保存为「桌面视图」，挂件标题旁下拉即切 |
| 6 | **每条任务多个链接** | 网页 → 默认浏览器；文件夹/文件 → 资源管理器；支持 UNC（\\server\share\...）；支持拖拽文件/文件夹/网址、粘贴路径 |
| 7 | **不做系统级提醒** | 不弹 Windows 通知；**逾期只在界面上标红**（危险色 #C4553B） |
| 8 | **开机自启 = 设置项** | 默认关闭；托盘常驻、关窗口只收进托盘不退出；单实例 |
| 9 | **视觉血统 = dsh-claude-style，执行契约 = 08** | 暖纸底、陶土橙唯一强调色、衬线标题、输入框三态、克制动效。视觉方向见 02，组件尺寸/状态/令牌的验收以 08 与 ../design/ui/tokens.css 为准 |
| 10 | **弹窗只能显式关闭** | X / 取消 / 保存 / Esc；**点击遮罩不关闭**，避免误触丢输入（见 02 §5.1） |
| 11 | **收起状态记忆** | 下次打开保持上次的收起/展开状态；收起后再启动直接显示胶囊（见 02 §4） |
| 12 | **过去时间不可选** | 日期时间选择器：今天以前的日期、今天已经过去的小时/分钟置灰不可选；确定时再次校验，选到过去弹提示并保持选择器打开（见 02 §5.2） |
| 13 | **快捷时间只显示 2 个** | 按用户实际设置过的到期时间统计（次数优先、最近使用次之，次数≥2 才算常用），不足用未来两个整点/半点补齐；选中今天时过滤已过去时间，并避免与当前时间过近（见 02 §5.2） |
| 14 | **逾期 = 到期时间早于当前时刻** | 同一天内已过时间也算逾期，显示「今天 10:00 · 已逾期 7 小时」；跨日显示「逾期 N 天」；顶栏/左栏/胶囊/进度/排序共用同一判定（见 02 §5.6） |
| 15 | **收件箱 = 无日期且无项目** | 只收「既没安排日期、也没归项目」的任务；有日期无项目、或有项目无日期都不算。删除项目后其下无日期任务自动回到收件箱（见 01 FR-2.2） |
| 16 | **项目 / 标签可管理** | 设置 →「项目与标签」→「管理」打开完整弹窗（项目+标签）；侧栏项目/标签分区标题右侧 pencil 打开单项弹窗。新建、行内重命名、删除；不做排序与自定义颜色。删除有关联任务时二次确认（显示任务总数 / 待办 / 已完成），无关联任务直接删除；两者均保留 toast 撤销（见 02 §5.3） |
| 17 | **侧栏导航可滚动、footer 固定** | 项目/标签多时不挤掉设置；只有中部导航区滚动，品牌与底部设置固定（见 02 §4.2） |
| 18 | **实施一次完成，不分阶段交付** | 新会话按 M0–M6 连续实施到整个工具完成、验收并打包 exe；里程碑只作内部检查点，不在中途停下等确认 |
| 19 | **UI 工程规范是实施契约** | 以 08-UI-ENGINEERING-SPEC.md + ../design/ui/tokens.css 执行；dsh-claude-style 只作设计血统，不单独作为验收依据；冲突时 08 > 02 > 截图；禁止裸 hex、Tailwind/CSS-in-JS、原生日期控件、点遮罩关闭 |
