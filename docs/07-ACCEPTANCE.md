## I. 10 步冒烟测试（手工，5 分钟）
1. 启动 exe → 挂件出现，显示今天任务。
2. 在挂件输入「测试任务 明天 10:00 高」回车 → 任务出现，时间为明天、优先级高。
3. 点勾选 → 任务进入已完成，计数变化。
4. 拖动挂件到屏幕左侧松手 → 位置改变；重启 exe → 位置保留。
5. 双击挂件 → 完整窗口打开。
6. 新建任务，拖一个本地文件夹进去 → 链接出现；点「打开」→ 资源管理器打开该文件夹。
7. 加一个 https 网页链接 → 点开 → 默认浏览器打开。
8. 筛选：标签「采购」+ 高优先级 → 结果正确；保存为「采购高优」→ 挂件下拉切换。
9. Esc 收起挂件 → 胶囊出现；双击胶囊展开。
10. 托盘 → 退出；重新启动 → 数据都在。
