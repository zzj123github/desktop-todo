## 1. 背景与目标

用户已在本机装好 Xcode，要把「桌面待办」做成个人待办 iOS App，要求**沿用当前风格**。本提案先给出高保真可交互 iOS 原型，确认后再进入 SwiftUI 实施。

设计血统不变：暖纸底、无纯黑纯白、陶土橙唯一强调色（可见面积 <10%）、衬线只用于展示级标题、1px 发丝线、短轻回弹动效。**iOS 与桌面共用 `design/ui/tokens.css` 同一套令牌，不另造色系。**

## 2. 风格沿用与 iOS 适配

| 维度 | 桌面基线 | iOS 原型 | 说明 |
| --- | --- | --- | --- |
| 色板 | tokens.css 全套 | **完全一致** | 纸底 `#FAF8F2`、卡片 `#FFFDFA`、陶土 `#D97757`、逾期 `#C4553B`、链接 `#184F95` |
| 展示标题 | 衬线 29px | 衬线 **32px** | iOS 大标题惯例放大，仍只用衬线 |
| 任务标题 | 13px | **15px** | 触控阅读字级 |
| 元信息 | 10.5px | **12px** | 同上 |
| 勾选框 | 18–19px 圆形 | **22px 圆形** | 命中区扩到 ≥44pt（含行内边距） |
| 任务行 | hover wash | **卡片组 + 发丝分隔** | iOS 无 hover，用 grouped card；按下 `--selected` |
| 主按钮 | 陶土 31px | 陶土 **40px** | 触控高度 |
| 弹窗 | 居中 modal | **底部 Sheet** | iOS 惯例；圆角 18 顶部 +  grabber |
| 进度环 | 40/34/26 | 同 + **64（小组件）** | 环内百分比留白规则沿用 |

交互规则沿用基线：**点遮罩不关弹层**（避免误触丢输入）、Esc/取消/保存关闭、删除保留撤销、逾期按到期时刻与当前时刻比较（同一天内已过时间也算逾期）。

## 3. 信息架构：桌面三形态 → iOS 映射

| 桌面形态 | iOS 等价物 | 原型场景 |
| --- | --- | --- |
| 完整窗口（1100×720） | **App 本体** | `App` |
| 桌面挂件（352 宽清单） | **主屏幕小组件**：小尺寸（进度摘要）+ 中尺寸（今日清单 3 行） | `主屏幕小组件` |
| 收起胶囊（284×54） | **锁屏胶囊** + 「接下来」矩形 accessory | `锁屏` |

App 底部 Tab 栏：**今天 / 视图 / ＋（陶土凸起）/ 已完成 / 设置**。

- **今天**：今天到期 + 已逾期；大标题 + 日期副行 + 进度环 + 筛选入口；状态 Tab（全部/待办/已完成）；待办卡片组 + 已完成折叠组；搜索框。
- **视图**：清单（今天/收件箱/已逾期/即将到期/已完成，带计数）+ 项目（彩色圆点）+ 标签（# 图标）；项目/标签分区标题右侧 pencil 管理入口（沿用基线）。点任一视图 push 进列表页，左上角返回。
- **＋**：打开「添加任务」Sheet，composer 自然语言输入（`明天 9:00 写周报 #会议 !高` 自动识别日期/标签/优先级），项目/标签 chips。
- **已完成**：已完成清单。
- **设置**：提醒（到期通知/声音/完成 Haptic 开关）、数据（项目与标签/导出/重置）、关于（小组件预览/使用说明）。

## 4. 关键交互（已在原型实现并截图验证）

- **添加**：composer 多行自动增高（≤5 行）、回车保存、实时解析预览 chips；日期工具展开 claude 风格内嵌日历（周一开头、今天陶土描边、选中陶土实底、过去置灰、时/分输入 + 快捷时间）。
- **编辑**：点任务行打开 Sheet——标题/备注/项目/标签/优先级/日期时间/链接列表（添加/删除/打开）；底部 删除（危险色）+ 取消 + 保存（陶土）。
- **完成**：点圆圈直接勾选（check-pop 回弹），移入已完成组，进度环/计数同步。
- **筛选**：日期/项目/标签/优先级 chips + 关键词，可叠加、有 fchips、可清除（沿用基线五维）。
- **管理**：项目/标签新建、行内重命名、删除（有关联任务先二次确认 + 撤销）。
- **小组件/锁屏**：点按直达 App「今天」；体验条切换三场景预览。

截图（`screens/`，无头 Chrome @2x 渲染，控制台零报错）：`ios-widget` `ios-lock` `ios-add` `ios-edit` `ios-views` `ios-settings` `ios-filter`。

## 5. 状态与数据结构

与桌面版同口径：`task{ id,title,notes,proj,tags[],prio,due,links[],done,doneAt,created }`、`project{ id,name,color }`、`tag{ id,name }`。原型存浏览器 localStorage（key `desktopTodo.ios.proto.v1`），仅本机。正式版纯本地存储（SwiftData / SQLite），**不做云同步**（见待确认 4）。

## 6. 落地映射（确认后）

- 技术栈：**SwiftUI**（iOS 17+），WidgetKit 做主屏幕/锁屏小组件，UserNotifications 做到期本地通知，UIImpactFeedbackGenerator 做完成 Haptic。
- 令牌 → SwiftUI：把 `tokens.css` 色板/圆角/字级映射为 `Color`/`Font`/`CGFloat` 常量（单一来源，禁裸色值），衬线展示标题用系统衬线（New York / Songti SC）回退。
- 工程目录、数据层、验收另立 `docs/` iOS 规格（确认后才写）。

## 7. 平台风险

- 小组件刷新受 WidgetKit timeline 预算限制，逾期分钟级文案在锁屏上可能不实时（用「已逾期」粗粒度 + 打开 App 精确）。
- 锁屏 accessory 着色受系统 tint 影响，陶土橙在深色锁屏上需验证对比度。
- 本地通知需用户授权；被拒后要有降级（App 内逾期标红仍在）。
- 未签名真机安装需开发者账号；模拟器验证优先。
