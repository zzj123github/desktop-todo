# 设计目录说明（静态原型 + 可交互原型）

本目录只保留最新原型：`app/` 是可交互原型 v1.3，`static-prototype.html` 是同步后的静态原型 v2.4，`app-fullpage.webp` 是唯一整页长图。旧探索稿与旧截图已清理，不参与验收。

> UI 实施契约（token、组件尺寸/状态、验收）在 `../docs/08-UI-ENGINEERING-SPEC.md` + `ui/tokens.css`；工程目录规范在 `../docs/09-PROJECT-STRUCTURE.md`；本目录只作像素与交互基准。

## 快速开始（体验可交互原型）

方式一：双击 **启动原型.bat**（需要本机有 Node.js；会自动开浏览器）。

方式二：在本目录打开终端，执行：

```bash
node server.mjs
```

然后访问：**http://127.0.0.1:8765/app/index.html**

> 单桌面体验：用完整窗口标题行的「收起到挂件 / 收起到胶囊」、双击挂件标题或双击胶囊，在三种形态间切换；点左栏底部「使用说明」（或顶部「怎么玩」）查看交互说明，点「重置演示」恢复初始 15 条演示任务。
> 数据存在浏览器 localStorage，只在本机；关闭页面不会丢。

看静态版：直接双击 **static-prototype.html**，或用上面的服务器地址访问 **http://127.0.0.1:8765/static-prototype.html**；整页长图是 **app-fullpage.webp**。

## app/ —— 可交互原型 v1.3（交互与行为基准）

纯 HTML/CSS/JS 的高保真交互原型，用来确认产品形态与手感；**不是最终应用**，但交互逻辑按最终产品实现。

已经能做的：

- **一个桌面，三种形态**：完整窗口（1100×720）、桌面挂件、收起胶囊同一时刻只出现一个，共用同一份数据；标题行右侧「收起到挂件 / 收起到胶囊」、双击挂件标题、双击胶囊都能互切，关闭 X 或 Esc 只回到桌面；挂件与胶囊共用一个位置基准，按最近的屏幕角记忆，拖到四角切换形态时基准角保持不动
- **桌面挂件**：352 宽，常驻、可拖动、图钉、调透明度；任务行内直接勾选，点任务打开编辑；底部添加区默认只显示「+ 添加任务」按钮，点开才展开完整输入框（回车保存、Esc 或点挂件外收起）；双击标题打开完整窗口
- **收起胶囊**：284×54，只显示今天条数 / 逾期数 / 最近到期项 / 完成度；单击展开挂件，双击打开完整窗口，Enter / Space 也可展开
- **九个视图**：收件箱（无日期且无项目）/ 今天 / 已逾期 / 即将到期 / 已完成 / 项目 ×3 / 标签 ×3
- **状态 Tab**：全部 / 待办 / 已完成；已完成分组可折叠
- **筛选五维**：标签（项目+标签）、日期（今天/明天/本周/已逾期/自定义）、优先级（多选）、关键词搜索；筛选可叠加、有 chips、可清除
- **快速添加**：输入「明天 9:00 测试任务 #设备」这类自然语言，自动识别日期、标签、优先级、链接；Ctrl+N / N 聚焦输入框
- **编辑任务**：标题、备注、项目、标签、优先级、日期与时间、多个链接（打开 / 排序 / 删除）、添加链接时一次填写地址与标题、拖入文件/文件夹添加链接、删除任务
- **链接标题与地址**：标题默认自动生成（URL 去协议截 44 字、路径取最后一段）；添加行同时有地址与标题（可选）两个输入，任一输入回车或点「添加」提交，地址无法识别（如 `javascript:`）时 toast 提示且不添加、不清空；点击标题或路径进入同一行内编辑，标题与地址两个输入一起出现，保存后按新地址重新识别网页 / 文件夹 / 文件并更新左侧图标；Enter 或失焦保存、标题留空回退自动标题、地址无效 toast 并保持编辑态、Esc 取消，两个输入之间切换焦点不会提前提交；没有链接时显示「还没有链接」，拖拽区主文案「把文件 / 文件夹拖到这里，或粘贴路径」+ 副文案「拖入后自动识别为文件、文件夹或网址」
- **链接直挂**：网页、本地文件夹/文件、UNC 共享路径；点链接先在原型里弹出「打开链接」说明（真实应用会按类型调浏览器/资源管理器）
- **挂件与胶囊位置**：拖动后按最近的屏幕角记录基准点；从窗口收起时恢复上次形态（挂件或胶囊）和同一个角，刷新/重启后仍在原位
- **日期时间选择器**：全部日期/时间输入改为自绘的 claude 风格选择器（编辑弹窗、筛选「指定日期」、输入框「指定」三处共用）：周一开头日历、今天陶土描边、选中陶土实底、时/分输入 + **2 个按常用度动态生成的快捷时间**、「清除 / 取消 / 确定」；时间行与快捷 chip 在同一行，既可点 ⌄ 展开小时/分钟列表选择，也可直接在时/分输入框里键入（点输入框不会关掉选择器），Esc 只关选择器、点遮罩不关弹窗；**今天以前的日期、今天已过去的小时/分钟置灰不可选**，键入过去时间点确定会提示「不能选择当前时间之前」
- **逾期判定**：按到期时间与当前时刻比较，**同一天内已过时间也显示逾期**（如「今天 10:00 · 已逾期 7 小时」或「已逾期 20 分钟」）；顶栏逾期数、左栏计数、胶囊、进度环、排序同步；新建任务默认时间不再落在过去
- **输入框细节**：1px 暖灰发丝线、焦点只加深边色 + 极轻投影，不画灰色光环（对齐 dsh-claude-style 0.20.3 的输入体验）
- **输入自动换行**：添加框是多行输入，超过一行自动换行并增高（最多 5 行，再长内部滚动）；Enter 保存、Shift+Enter 换行、中文输入法按回车不会误提交；挂件与完整窗口一致
- **滚动条**：列表、弹窗、输入框统一细暖灰滑块、透明轨道、无上下箭头（标准 9px / 浮层内小列表 6px）；输入超过 5 行后按标准样式内部滚动，悬停加深
- **弹窗规则**：新建/编辑/设置/链接等弹窗只能通过 X、取消、保存或 Esc 关闭，**点遮罩不会关**，避免误触丢输入
- **项目/标签管理**：两个入口——设置 →「项目与标签」→「管理」打开完整管理弹窗；左栏「项目」「标签」分区标题最右侧的 pencil 打开对应单项管理弹窗。弹窗内可新建、行内重命名、删除；重名/空名被拒；删除有关联任务（含已完成）先二次确认并显示总数/待办/已完成，无关联直接删除，均保留 toast 撤销；左栏项目、标签行悬停时也有删除图标；被删项目下的任务自动变成「无项目」，被删标签会从任务上移除；删除当前正在看的项目/标签会自动回到「今天」；编辑弹窗里新建的项目/标签，关闭弹窗后左栏立即出现
- **弹窗原地更新**：新建/编辑弹窗里点项目、标签、优先级、日期 chip 只更新内容，**不会整体闪烁或重播入场动画**；首次打开才有 240ms 入场；滚动位置保留
- **使用说明**：左栏 footer 在「设置」之上新增「使用说明」入口，打开应用内弹窗（wide 502）：三种形态 / 添加与编辑任务 / 链接 / 筛选与桌面视图 / 快捷键 / 数据与设置六节，正文滚动，footer 只有「知道了」；X / 知道了 / Esc 关闭，点遮罩不关；demo bar 的「怎么玩」入口保留
- **其他**：设置（置顶、透明度、开机自启、全局快捷键、数据导出/重置）、撤销删除、Esc 关闭浮层、快捷键 Alt+1..5 切视图
- **进度环**：环内百分比数字固定留白，2 位数与 100% 都不贴圆环（40/34/26px 三种尺寸统一），100% 时数字略缩以保持同样间隙
- **入口不重复**：标题行只保留进度环、收起到挂件 / 收起到胶囊、新建与关闭；搜索只在筛选行右侧放大镜与 `/` 快捷键；左栏底部固定「使用说明」与「设置」两个入口；项目/标签整体管理只在设置里，单项管理只在分区标题右侧 pencil

体验路径建议：

1. 桌面形态：勾掉一条任务，看进度环与「已完成」变化；把挂件拖到别处；点标题行的「—」收成胶囊，再把胶囊拖到别的角，单击展开、双击打开完整窗口，看它是否停在最近的那个角
2. 完整窗口：点标题行的形态按钮来回切三种形态；左栏逐个点视图；点标签/日期/优先级筛选；搜索「模具」
3. 底部输入框输入「明天 9:00 整理桌面文件 #设备」回车，看新任务被解析到明天并带上标签
4. 点任意任务打开编辑，点链接看「打开链接」弹窗；把文件拖到弹窗链接区
5. 双击空白处快速新建；删除任务后点 toast 上的「撤销」
6. 设置里试透明度 90%/80%，或「重置演示」恢复数据
